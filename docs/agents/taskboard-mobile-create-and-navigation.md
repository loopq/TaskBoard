# 手机任务创建与分组导航修复

状态：实施、自测、腾讯云发布及线上核验完成；当前 release `32f71268a49e35fa0c34`。

## 1. 问题与证据

- 已查看用户提供的截图，以及两段录屏的连续抽帧：手机横滑时「进行中」卡片与「已完成」卡片重叠；创建录屏中输入「测试任务」后文本清空，但「待处理」数量仍为 0，录屏内没有出现新卡片。录屏无法证明每次触摸的事件类型，也无法确认请求是否发送或返回错误。
- `web/src/components/AddInput.vue` 是任务、列、子任务共用的输入组件。当前 `submit()` 在通知调用方之前直接清空草稿；Vue 事件通知没有等待调用方的异步成功结果。它同时绑定表单提交、失焦提交，并依靠按钮上的 `pointerdown.prevent` 保持焦点。错误时丢草稿是已确认缺陷；iOS 点击无效的具体事件原因仍待复现，不能先认定是 `pointerdown`。
- 调用链：`AddInput` → `BoardColumn.submitTask` → `store.addTask` → `api.POST /tasks` → 服务端 `createTask`。`store.run()` 捕获错误后提示并刷新看板，`addTask` 成功和失败均可能返回 `undefined`，调用方无法据此判断创建成功。新建列和子任务也必须一起检查。
- 布局风险：`.board` 的直接子项 `.normals` 未限制收缩，内部 `.col` 则使用固定 `flex-basis`（手机为 `86vw`）；父容器的实际占位与子列宽度可能不同，导致后续「已完成」列覆盖溢出的普通列。需要在浏览器量出边界验证，而不是用 `z-index` 或裁剪把问题藏起来。
- 用临时数据库启动现有 API，调用现有登录、读取看板和创建任务接口，成功创建含中文标题的任务。这只验证本地服务端链路，不证明线上接口或 iPhone 正常。浏览器控制连接在导航阶段报错，本轮没有完成浏览器复现。

## 2. 交互决策

推荐手机端使用「单列任务列表 + 顶部分组选择器」。桌面继续使用多列看板；断点沿用现有 640px。

| 方案 | 评价 |
| --- | --- |
| 整板左右滑动 | 当前列之外的信息不可见，切组需要连续滑动，还与纵向滚动、拖拽竞争手势，不作为手机主交互 |
| 所有分组纵向堆叠或折叠 | 能同时浏览多组，但已完成任务和长列表会让切组距离越来越长 |
| 单列列表 + 点击选择分组 | 推荐；手机只承担一个滚动方向，任意分组都能直接到达 |

- 顶部用原生 `<select>` 显示分组名和数量，选项来自现有 `columns`，不把三列名称写死，也不新增横滑标签栏或选择器依赖。
- 当前分组的任务占满可用宽度，只有任务列表纵向滚动。新建任务输入放在列表上方，按钮文字为「添加」，点击热区至少 44px；已完成组继续禁止新建任务。
- 初次进入默认待处理；切组不提交未完成草稿，保留各组草稿。删除当前空分组后回到待处理；新增分组成功后选中该组。普通分组的改名、删除、新建入口继续可达。
- 跨组移动复用详情中已有的「所在列」选择器；完成和取消完成继续使用现有按钮及服务端规则。详情链接打开后，让背后的手机列表选中任务所属分组。
- 保留现有组内排序能力。手机分组排序通过列操作菜单的「上移 / 下移」复用 `moveColumn`，因为单列视图无法再靠同时拖动多个列头排序。桌面的列拖拽与跨列任务拖拽继续保留。
- 明确调整创建语义：按钮点击或键盘确认提交，失焦只保留草稿；选中文输入法候选词不应创建任务。取消「失焦自动创建」会改变既有行为，此项随本方案一起审批。

## 3. 最小实施范围

1. **公共输入组件**：将通知式添加改为可等待成功结果的提交回调；使用原生表单和稳定的提交按钮，去掉失焦自动提交与阻止 pointerdown 默认行为。组件只保留草稿、提交中和必要的输入法状态。提交中防重复；收到成功结果才清空；失败保留原文并在控件附近显示可见反馈，避免错误提示被键盘挡住。请求期间禁止编辑或确保不会误清新输入。
2. **所有调用方**：任务、列、子任务的创建函数返回明确成功结果，复用已有 API 与统一错误处理；不要更改其他写操作的错误约定。仅在任务创建成功后定位新卡片。认证失效仍遵守现有退出登录流程。
3. **手机展示**：在 `Board.vue` 增加当前分组 ID，继续使用原有列与任务数据。优先保留同一套 `BoardColumn` 实例并按断点/当前分组切换可见性，避免双份数据和切组丢草稿。对分组被删除、详情链接、窗口跨断点切换作必要处理，保留有效选择。
4. **布局根因**：修正普通列容器的占位和收缩约束，让桌面各列也不会覆盖；手机取消整板横向滚动与吸附，明确当前列宽度与唯一纵向滚动区域。复用现有安全区、字号规则，验证键盘展开后提交入口可见；仅当真机证据需要时才加入额外视口补偿。
5. **受影响文件**：`web/src/components/AddInput.vue`、`Board.vue`、`BoardColumn.vue`、`TaskDrawer.vue`、`web/src/store.ts`、`web/src/style.css`；只有排序启停确有需要时才改 `web/src/sortable.ts`。不新增业务依赖，不改变 API、数据库或任务/分组 ID。
